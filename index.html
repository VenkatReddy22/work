Settings and backup

Make a fine-grained token at github.com/settings/personal-access-tokens/new. Under Repository access choose Only select repositories and pick this repo. Under Repository permissions set Contents to Read and write. The token stays in this browser only. In a public repo, anyone can read your hours.

Any biweekly start works. Every 14 days after it starts a new one, and weeks run Monday to Sunday from it.

Shifts before your first full biweekly (like training) are counted in Biweekly 1.

Fill-ins: {day} {date} {iso} {start} {end} {partner} {hours} {break}. Press Enter for a new line.

Entries are saved in this browser on this device. Download a backup now and then.
